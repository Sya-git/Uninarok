# AccountSex

- **Kind:** Shared enum
- **Underlying type:** `byte`
- **Description:** Sex/account-kind values used by networking and gameplay. On the wire it is one byte.

| Name | Value | Description |
|---|---:|---|
| `SEX_FEMALE` | `0` | Female account/character value. |
| `SEX_MALE` | `1` | Male account/character value. |
| `SEX_SERVER` | `2` | Server value. |
